# Game Baru

Proyek Godot 4.6.3 (GDScript), native Android tanpa WebView.

## Status
Tahap 1: persiapan proyek dan pipeline APK uji. Belum ada gameplay, karakter, peta, atau UI utama.

## Cara mendapat APK uji
1. Buka tab **Actions** di GitHub, pilih **Build APK (Godot 4.6.3)**, tekan **Run workflow**.
2. Setelah selesai, buka run tersebut dan unduh artifact `game-baru-debug-apk`.
3. Pasang APK di HP (izinkan "pasang aplikasi tidak dikenal").

Catatan: APK ini ditandatangani kunci debug, hanya untuk uji. Belum ada GitHub Release.
